# Этап: обучение базовой модели

## Постановка задачи

Решается задача бинарной классификации уровня социального доверия на основе данных ESS.

Целевая переменная:

* `ppltrst` → преобразована в бинарный признак (`target = 1`, если ≥ 5)

## Используемые признаки

Рассмотрены три группы признаков:

* **BASE (media only)**: tvtot, rdtot, nwsptot, netuse
* **FULL (media + values)**: BASE + ценностные измерения (openness, conservation, self_transcendence, self_enhancement)
* **FE (feature engineering)**: агрегированные и трансформированные признаки

## Модели

Использованы baseline-модели:

* DummyClassifier
* LogisticRegression (основная)
* KNeighborsClassifier

## Метрики

* Основная метрика: **F1-score**
* Дополнительная: **ROC-AUC**

Выбор обусловлен необходимостью учитывать баланс precision и recall и способность модели различать классы.

## Улучшение модели
Выполнена оптимизация порога классификации.
стандартный порог: 0.5
оптимальный порог: 0.1
улучшенный F1-score: 0.771
Это показывает, что качество модели можно повысить без изменения архитектуры.

## Основные выводы
1. LogisticRegression показала лучшие и наиболее стабильные результаты
2. признаки медиапотребления дают основной вклад в качество модели
3. ценностные переменные увеличивают ROC-AUC, но не F1-score
4. feature engineering не дал прироста качества
5. переобучение отсутствует
6. оптимизация порога позволила дополнительно улучшить модель
